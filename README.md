# Alana's Birthday — GTA VI Edition

## Como abrir
1. Extraia esta pasta.
2. Abra o arquivo `index.html` no navegador.
3. Para editar, altere os textos em `index.html`.
4. Para alterar cores, fontes e layout, edite `style.css`.
5. Para alterar data, mapa e WhatsApp, edite `script.js`.
